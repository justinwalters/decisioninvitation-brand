# DecisionInvitation brand

The source identity system for DecisionInvitation: a private response space for decisions that need independent perspective before an accountable decision.

## What is here

- `BRAND-GUIDELINES.md` — positioning, voice, mark use, and governance.
- `assets/logo/` — working SVG logo assets.
- `assets/tokens/` — portable JSON and CSS tokens.
- `site/` — the public identity-page content specification.

The live public implementation is maintained in the DecisionInvitation product repository at `brand.html` and `brand.css`, then deployed as `https://decisioninvitation.com/brand`. Keep the page and these guidelines aligned; this repository owns the identity, not the product runtime.

## Status

This is a working visual system. It has not been legally cleared as a word mark or design mark. Do not describe any asset as trademark-cleared, exclusive, or available without qualified counsel.

## Relationship

DecisionInvitation is designed to stand on its own. It is part of the aSUKIra group, sharing a standard for calm, evidence-aware work. It does not use the aSUKIra or Suki lockups, brushmark, or name treatment.
