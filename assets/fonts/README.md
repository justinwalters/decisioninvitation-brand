# Typography Sources

DecisionInvitation uses unmodified static Sora Regular and SemiBold files in TTF and WOFF2 formats. `provenance.json` records source URLs and SHA-256 hashes. `LICENSE-Sora.txt` contains the SIL Open Font License 1.1.

Do not substitute aSUKIra typography in DecisionInvitation materials. System fallbacks are for failure handling only, not approved composition.
