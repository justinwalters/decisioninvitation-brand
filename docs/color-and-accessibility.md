# Color and accessibility

DecisionInvitation uses a cool, analytical palette. It is intentionally independent from the parent identity.

| Role | Name | Value | Primary use |
|---|---|---:|---|
| Text and structure | Register | `#211B2B` | Body text, rules, the commitment gate |
| Action and focus | Cobalt | `#3346C8` | Links, controls, active states |
| Supporting field | Periwinkle | `#C3CCFF` | Analytical lanes, selected regions |
| Primary field | Optic | `#F7F8FF` | Page and document backgrounds |
| Reverse field | White | `#FFFFFF` | Reverse type and clean space |
| Provenance only | Suki Orange | `#D54B1E` | The post-threshold lineage point |

Register on Optic and Cobalt on Optic are the primary text pairings. Validate every new foreground/background combination to WCAG 2.2 AA before release. Do not rely on color alone for state, ownership, urgency, or approval.

Suki Orange is not a DecisionInvitation action color. Keep it at or below two percent of a composition, never use it as a full field, and never use it for warnings, destructive actions, or status. Its sole branded role is a small point after the commitment threshold.

For print, the supplied values are RGB references. A printer must establish stock-specific CMYK or spot-color conversions and approve a physical proof before any output is described as press ready.
