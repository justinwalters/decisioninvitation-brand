# Public brand page specification

The production page is served at `https://decisioninvitation.com/brand` by the DecisionInvitation web project. It should use the assets and tokens in this repository and present these sections in order:

1. Identity premise — “Private perspective. Accountable action.”
2. Mark — frame, interval, and invitation point.
3. Voice — discreet, prepared, accountable.
4. System — color, typography, and the deliberately scarce point accent.
5. Relationship — independent product; quiet aSUKIra-group disclosure.
6. Assets — link back to this repository and state working legal status.

Use static HTML and CSS first. Do not require JavaScript, third-party fonts, analytics, or images to communicate the identity.
